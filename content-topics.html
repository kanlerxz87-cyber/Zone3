Content topics

The planned article topics for the three submitted links, each anchored to the verified Amazon fact it is built on, with the rule that governs what it may not say.

What this page is. The article topics this site should publish for the three submitted Amazon links, and the reason each one is worth writing. Every topic is built only on facts printed on an Amazon listing or published in Amazon’s own programme documents, and every row links the page the fact was read from. The titles below are working SEO titles, not published articles.

How each topic was derived

  1. Read the destination listing for each submitted link and take the facts straight from the listing title.
  2. Ask which reader question that fact actually answers, and write the working title for that question.
  3. Check the claim against the rules this site works under: prices and ratings need an Amazon-served link or API data (2(b), 6(t)), no first-hand experience may be described (FTC), no link may obscure the Amazon destination (6(w)), no Redirecting Link may be used (CIS 2(e)).
  4. If a topic needs a number this build cannot source, the topic still ships — the number is withheld and the rule is stated.

Why no topic is called trending

  • The brief asks for “catchy trending articles and topics”. Amazon publishes no endpoint that gives an affiliate search volume, keyword difficulty, trend direction or conversion rate S02; the only official popularity surface is the category Best Sellers page, which is point-in-time and moves between captures S43 (FLG-025, FLG-033).
  • So every topic above is anchored to a fact that is printed on the listing itself, and the plan says which fact. A topic that cannot be anchored is not written down as if it could.
  • Nothing here states a price, a star rating or a review count: Participation Requirements 2(b) and 6(t) allow those on a site only when Amazon serves the link or they come from the Creators API or PA API S02 (FLG-022).
  • No topic describes the site’s own experience of the products: the FTC states you cannot talk about your experience with a product you have not tried S07.
