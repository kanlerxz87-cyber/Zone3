Verification standard what had to be true before a value reached a table

  1. The source had to be an official page — Amazon.com or Amazon Associates Central, or a government regulator such as the FTC. Third-party blogs, affiliate guides and SEO tools were read for orientation but not used as sources for any value on this site.
  2. The page had to actually be retrieved in this session. Nothing is cited from memory.
  3. If a value could not be read from an official page, the cell was left blank and flagged. Nothing was inferred, estimated, interpolated or carried across from a similar product.
  4. Every volatile value carries the timestamp of the page it came from. Prices and ratings were captured from Amazon search-result pages whose Amazon request id (qid) decodes to the true request time, so those timestamps are exact rather than approximate.
  5. Every external link the site emits must appear in the allowlist. The build fails otherwise, so a stray unverified URL cannot silently ship.
