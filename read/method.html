How we check

The method, the source list, and the questions this site cannot answer yet.

This site is generated from a verified data file, not written from impression. Each product statement is a dated capture of an official Amazon page; each policy statement is a dated quote from Amazon's Associates pages or the FTC. The generator refuses to publish a table row that has no source link, and the site's checker fails the build if a row loses one.

The register behind these pages — 90 dated official sources, an operations dashboard, a per-row verification log and a flagged-items list — is published alongside this editorial layer, because the point of evidence is that you can look at it.

One thing to know before you trust us completely: a second reader-facing version of this project, Air Fryer Field Notes at /site/, was built by another session on the same day from the same verified data. Both are published, neither is hidden, and the overlap is recorded as Z14-F-04 on the flagged register for the owner to resolve. It is stated here rather than tidied away, because two sites agreeing on the same evidence is itself a check on the evidence.

The pipeline, in order

  1. Each submitted link is followed and its final URL and served page title are recorded verbatim, with the date.
  2. Only text from those captures enters the copy. A number that is not in a capture does not appear on this site.
  3. Policy statements are quoted from the Amazon Associates Operating Agreement and Program Policies, and from FTC guidance, each with its own dated source entry.
  4. The generator fails if a table row has no official-source link, if a price pattern appears, or if a star-rating pattern appears.
  5. Anything that cannot be confirmed is left blank in the data and published on the flagged register instead of being filled in.

What that buys you. A page you can audit. If you find a statement here that the official page does not support, that is a defect, and the flagged register is where we would have recorded it. Open the register.
