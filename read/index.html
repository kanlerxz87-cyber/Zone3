Four rules this site will not break

We quote, we don't guess

No prices, no stars — on purpose

Amazon's Program Policies allow a site to show prices and availability only when Amazon serves them, and star ratings only when they come through the Creators API. We have neither, so we publish neither rather than something stale. S02
