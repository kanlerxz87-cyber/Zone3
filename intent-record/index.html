Field rules

  • Intended ASIN, official listing URL, confirmation date and confirmation source are the INTENT fields. They are filled only when the owner supplies the intended product and an official page confirms it. None is filled on this pass.
  • Observed redirect target fields record what the submitted short link opened on the observed date. They are a separate field and are never copied into the intent fields.
  • A submitted code of 9 characters is not an ASIN. Amazon's Creators API defines ItemIdType ASIN as a 10-character identifier (see AE-V-02).
