A NOTE ON OUR LINKS

As an Amazon Associate I earn from qualifying purchases. How we work

PRIVACY & MEASUREMENT / UPDATED 19 NOV 2026

Count the questions.
Not the people.

No advertising pixels, no visitor profiles, no invented conversion numbers.

Production collection is not active.

The production endpoint is not configured. The first-party counter therefore makes no analytics request. A real same-origin collector is available in the development preview for testing only; preview tests are not campaign results.

What the counter is built to measure.

One active runtime schema defines five events: page_view, outbound_click, guide_view, intent_view and flag_view. These are site events, not unique people, sessions or purchases. A click does not prove an order or commission.

When enabled, it sends only an allowed event, a page path without query string or fragment, and—for outbound clicks only—an approved Amazon host and public product token. The collector assigns the UTC day and stores daily aggregate counts. It does not keep raw event rows, IP addresses, user agents, referrers or visitor identifiers. Requests omit credentials and referrer information. Like any web request, the connection necessarily exposes an IP address to the receiving host and may include browser-supplied headers such as User-Agent. They are not event-body fields, and this collector does not log or store them.

Global Privacy Control, Do Not Track, or Save-Data disables the counter. Analytics writes no cookies, localStorage, sessionStorage or fingerprint. The browser makes no request if configuration is missing or invalid.

Other local browser behaviour.

Search runs locally after downloading a public search index; search text is not sent to analytics. Suggestions are saved in localStorage only when you explicitly press Save. That record contains proposal choices and a save date, not an identity, and is not sent to a server. You can clear it on the suggestions page. Export downloads a JSON file to your device.

The hosting and retailer limits.

GitHub: what is GitHub Pages? states that GitHub logs visitor IP addresses for security. Our code cannot prevent hosting-provider logs. If you open Amazon, that site handles the visit under its own policies. An external collector host or reverse proxy must also be configured not to retain request logs; this code cannot certify an undeployed host.

The reference collector retains aggregate counts for 90 UTC days, rejects unapproved origins and oversized/invalid payloads, and exposes totals only with a server-side read token. The reference has a global write ceiling as a basic abuse guard; it is not a bot-detection or unique-session system.

Orders belong in authorized reports.

No visitor-level Amazon sub-tag is assigned. The campaign ledger stays empty until authorized first-party evidence is available, with timestamp, source, channel, eligible sessions, clicks, reported orders and provenance. Amazon Associates Program Policies governs Associates links and reporting, including its end-user restriction in Participation Requirements 2(b).

See the current measurement configuration and what is still needed for production.
