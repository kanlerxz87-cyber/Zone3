## Irregularities

**IRR-01 (high, compliance — cross-scope, logged not fixed).** Program Policies 2(b), read
live, requires the Associates ID/"tag" as a URL parameter on each link to an Amazon Site. The
live product links render without `tag=`. This is the same defect PR
[#192](https://github.com/kanlerxz87-cyber/Zone3/pull/192) (session `5d460e79`) is fixing via
`tools/attach_tag.py`. Per the board's cross-scope rule this session did not edit that task; it
independently confirmed the clause and logged a coordination note. FLG-003 stays unresolved;
no claim that the supplied short links are valid or invalid is made.

**IRR-02 (medium, machinery — fixed this session).** The published house style
(`site/style-guide.html`) forbids a banned hype/trend register and says a script fails the
build when a page slips. The enforcing script (`tools/cba81fa5_lint.py`) scanned only the
`site/` archive; the **live publication** was scanned by `tools/check_publication.py` for
price/rating/experience claims but **not** for the banned hype/trend phrases. A scan found two
genuine uses on the live `about.html` ("another **must-have** list", "**trending** status").
Fixed in the generator source and closed with a new gated scan.
