What "continuously optimise" can actually mean here

The optimiser has five permitted levers and seven prohibited ones, listed in the table above. The permitted set is real and worth automating: which product occupies the top slot on a page (by derived EPC), the copy and layout around each link, which static sub-tag a page or slot carries, the product set itself (you may add or delete products and their links at any time without approval), and hygiene pruning of dead listings and malformed tags.

The prohibited set is exactly the set an unconstrained growth agent reaches for first — self-clicking to test the funnel, seeding orders through staff or friends, bidding on brand keywords, per-visitor attribution, incentive loops, and intercepting Amazon's own flows. Note the asymmetry: a malformed or untagged link does not merely lose that sale, CIS 2(g) disqualifies the purchase because it was not correctly tracked — which is why link validation is treated as a revenue control in the build, not as compliance paperwork.
