Blocking finding — the three product links do not identify any product

Each submitted link is a 9-character identifier. Amazon defines an ASIN as a 10-character alphanumeric code, and https://www.amazon.com/dp/<id> returns a Page Not Found error page for all three. When followed, each link resolved to a different unrelated product (a CHEFMAN dual-basket fryer, an Emeril Lagasse toaster oven, and a Chefman 8-Qt fryer) carrying plpRedirect=mhFallback — Amazon's fallback route, not a product deep link.

Consequence: no product name, price, rating, review count, category or commission figure can be stated. Those cells are left blank across this site rather than estimated. See Flagged for review (FLG-004…FLG-008).

Findings at a glance

The automation brief is achievable; the product list is not. The research → analysis → content → publish → optimise loop is fully specified and implemented in tools/. What is missing is a valid product identifier and an Associates account, both of which only you can supply.

Three requirements in the brief collide with Amazon's own rules. Price analysis as a user-facing price-alert feature is prohibited; click tracking per visitor via dynamic sub-tags is prohibited; trending / high-converting detection has no official Amazon data source at all. Those features are excluded by design and each is documented with the clause that excludes it.

PA-API 5.0 is dead. Amazon's own documentation host now serves a deprecation notice returning 403 AccessDeniedException, directing integrations to the Creators API. Any affiliate tooling built on PA-API 5 — which is most of it — needs migrating. FLG-014.

API access is itself gated. Creators API requires at least 10 qualifying sales in the past 30 days, so a brand-new affiliate account cannot automate product research at all. The platform queues research jobs until credentials exist. FLG-020.

Amazon added explicit AI-agent rules, and this platform obeys them. The IP License now contains Agent Terms: an agent must declare itself as Agent/<name> in its User-Agent, must not mimic human keystroke patterns, must not solve CAPTCHAs, and must not circumvent access controls. Most tooling advertised as a fully autonomous Amazon bot cannot say that about themselves.
