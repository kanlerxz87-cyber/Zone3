Coverage

32 requirements decomposed from the brief: 16 built-blocked, 15 delivered, 1 not-built-compliance.

Nothing is marked delivered that is not present in the repository or on this site, and the nine not-built-compliance / built-blocked splits are deliberate: the first means "we declined on policy grounds", the second means "we built it and the data is missing". Those are different answers with different follow-ups, so they are recorded separately.

Definitions

  • delivered — Built and verified in this repository / on this site.
  • built-blocked — Code and specification complete; the data it would present is blocked on an official input.
  • not-built-compliance — Deliberately not built, because the Program Policies prohibit it.
