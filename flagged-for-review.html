Flagged for Review

Unverified items and irregularities, published for owner review before the site goes live. None of these block publication. Nothing here was inferred or invented.

Irregularities found during this session

  • Short-link ASINs do not resolve directly. B04G1MEwY, B02NbDxp3 and B00hJ57DV return 404 on direct /dp/ lookup on amazon.com, amazon.co.uk, amazon.de, amazon.ca, amazon.in and amazon.com.au. Only the link.amazon short links resolve, redirecting to destination ASINs B0CDY277D3, B09B7SB46R, B08DKYBTPH respectively.
  • Short-link code ≠ destination ASIN. The code embedded in each short link is not the ASIN of the product it redirects to. Product tables use the destination ASIN (verified page) as the product identity.
  • Product detail content blocked. Amazon's bot-protection checkpoint prevented reading price, star rating, review count and availability from the official pages.
  • Repo was near-empty at session start. Only README.md existed; no code, configuration or data.
