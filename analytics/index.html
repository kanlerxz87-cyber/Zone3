Disclosure: As an Amazon Associate I earn from qualifying purchases. Links to Amazon are marked sponsored. How disclosure is handled

Measurement desk · first-party only

What this site measures, and what it refuses to measure

The counter below runs on every published page of this site. It records what a reader actually did — a click they made, a page they opened, a call to action they chose, a disclosure that came into view. It sets no cookie, creates no identifier, and stores nothing about a person. The collection endpoint is not configured yet, so nothing leaves the reader's browser.

Status. The counter and the collector are built and tested (2026-11-17). The collection host is not chosen, so every event stays in the reader's own browser. The five events below are a proposal: the owner brief asked for five recorded events without defining them, and decision DEC-03 holds the choice of host open. Nothing on this page is presented as an approved plan, and no traffic, popularity or earnings figure is claimed anywhere.

Open items: flagged for review · decision DEC-03 · open question Q8 · campaign ledger

The rules the counter must not break

These are the constraints the implementation is written against, each with the rule it comes from.

R2No personal data and no persistent identifier. The counter stores no cookie, sets no cookie, generates no device or browser fingerprint, and creates no visitor identifier. R3No third-party request. The counter only ever talks to an endpoint the owner controls. The endpoint contract

The counter posts one JSON object to the collector. The collector drops any field that is not on the list before it writes anything, so a later client change cannot quietly widen what is stored.

MethodPathPurposeResponseSource
POST/erecord one event204 with no body once the event is written; 400 when the payload does not match the contract3C-S01 · repo:data/analytics/events.json
GET/statsaggregate counts by event, page and target, computed from the stored events200 with a JSON summary3C-S01 · repo:data/analytics/events.json

Allowed fields: e, p, t, l, a, ts, d. Maximum body: 4096 bytes. Never stored: IP address; User-Agent string; Referrer header; cookies; any visitor identifier; price, rating, review count or any other product attribute.

The measurement ledger

Empty by design, like the campaign ledger. A row is added only when the numbers behind it come from an authorised first-party report, with the report named and dated.

Date writtenSourceChannelEligible sessionsClicksReported orders
No rows yet. A row is written only from a named first-party report, with its date.
  • timestamp — the date the row was written
  • source — the first-party report the numbers came from, named and dated (for example an Associates report for a named day, or this site's own event store for click counts)
  • channel — the path or campaign the row describes
  • eligible_sessions — sessions as Amazon defines them: a click on a Special Link opens a session that ends 24 hours later or when the customer returns to Amazon by another means (Participation Requirements, PF-12)
  • clicks — outbound clicks observed by this site's own counter, or the click figure in the named report
  • reported_orders — orders as reported in the named first-party Amazon report; never estimated
