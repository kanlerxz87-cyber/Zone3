## Verification policy

- Every asserted value links to an official source (amazon.com, affiliate-program.amazon.com, ftc.gov).
- Values that cannot be confirmed from an official source are **left blank and flagged** — never inferred.
- Data captured **2026-11-13**; prices/deals are point-in-time observations.
