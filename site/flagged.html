How items get closed

  1. Answer the question it waits on. I2-F-03 and I2-F-04 close the moment a tag and an intended ASIN are supplied; I2-F-02 closes when the API is eligible.
  2. Re-verify against the official page. A closed item is closed by a dated read, not by an assertion that it is fine now.
  3. Record it in the task board. The change and its evidence are logged so the next session does not silently reopen or duplicate it.

Nothing on this page is a guess. Where a value is missing, the reason is a rule with a source link, or a fetch that returned nothing attributable. If you think one of these is wrong, the source link is the place to check it.
