As an Amazon Associate we earn from qualifying purchases. Verification policy: every asserted value has an official source URL; anything unconfirmable is blank + flagged (Flagged). No values are inferred.

Verification method

  1. Resolve: each supplied link.amazon/<code> URL fetched directly; final Amazon product URL recorded; target stability confirmed by repeated fetches (×2–×3).
  2. Capture: product facts (title, brand, price, list price, rating, review count, velocity, deal badge) read from official Amazon.com product/search pages on 2026-11-13.
  3. Control-test: junk inputs (ZZZZZZZZ99, B0FAKE1234) and a real-but-unregistered ASIN tested to prove the resolution behavior is real, not a generic redirect.
  4. Policy capture: Associates Operating Agreement and Program Policies fetched from affiliate-program.amazon.com; FTC guide from ftc.gov; document "Updated" dates recorded.
  5. Blank-and-flag: any value not confirmable from an official source is left empty, marked unverified, and published on the Flagged page with the failed attempt documented.
